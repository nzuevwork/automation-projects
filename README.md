# Automation Projects

This repository contains real-world automation and system administration projects
that demonstrate practical business solutions with PHP and Python.

Each folder contains a standalone project with clear purpose, structure,
and documentation.

## 📁 Projects

### 📌 Alisa + Bitrix24 + Home Assistant
Automates voice notifications for CRM events (Bitrix24 → Home Assistant → Yandex/Siri voice alerts).

📂 `alisa-bitrix-homeassistant/`

### 📌 Bitrix24 Logistics Checklist
Handles business automation for Bitrix24 task/checklist processing.

📂 `bitrix-logistics-checklist/`

### 📌 Website Security Auto-Ban
A lightweight PHP script to improve website security by blocking suspicious activity.

📂 `website-security-autoban/`
